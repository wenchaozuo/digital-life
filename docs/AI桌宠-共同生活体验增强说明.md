## 本轮新增的核心内容

- 将“共同生活”确立为数字生命核心机制的体验层；
- 增加现实时间、离线时长、回归问候和生活节奏；
- 增加 `CompanionMode` 陪伴模式；
- 增加 `LifeEvent` 生活事件聚合；
- 增加 `ActivitySession` 共同活动统一模型；
- 将专注陪伴设为 V0.1 的首个高频活动；
- 增加生命日记、今日片段、自然回忆和关系里程碑；
- 将 Agent 任务纳入 V0.4 的共同工作体验；
- 明确成长通过称呼、主动方式、兴趣和合作习惯自然呈现；
- 禁止单一好感度、离线惩罚、情绪压力和付费关系绑定；
- 明确日记必须有来源，不能伪造共同经历或保存完整思维链；
- 明确时间与模式判断本地执行，避免持续模型调用和 Token 浪费；
- 明确桌宠、状态中心、语音、活动和 Agent 始终共享同一 `life_id`。

## 对开发路线的影响

### V0.1

新增最小共同生活闭环：

- 现实时间和离线时长；
- 回归、早晚和安静存在；
- 陪伴模式解析；
- 专注陪伴活动；
- 基础生活事件；
- 勿扰与低成本本地表现。

### V0.2

新增：

- 活动到候选记忆的完整链路；
- 今日片段与生命日记；
- 关系里程碑；
- 自然回忆候选；
- 日记来源和删除治理。

### V0.3

新增：

- 轻量游戏；
- 虚拟散步和轻叙事场景；
- 节日、纪念日；
- 背景、动作、TTS 和 LipSync 联动。

### V0.4

新增：

- Agent 任务作为共同工作活动；
- 任务完成/失败回顾；
- 技能经验和过去任务回调。

## 基线优先级

后续文档与实现冲突时遵守：

`统一需求基线 Baseline 1.1 > 共同生活系统设计 / 详细设计 > 产品概念 > 功能图谱 > 调研文档`

本轮只借鉴成熟产品的通用体验方法，不复制其角色、剧情、UI、文案、资源或专有实现。
